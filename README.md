# Finlite · local_pwa

Автономный планировщик распределения поступлений. Сохранённый шаблон применяет правила сверху вниз: фиксированная сумма вычитается из остатка, процент считается от остатка после предыдущих правил. Если денег недостаточно, расчёт останавливается. Приложение не выполняет платежи и не ведёт учёт фактических трат.

## Запуск и установка

Для локального просмотра нужен Node.js 20+:

```sh
npm start
```

Открыть `http://127.0.0.1:4173`. Устанавливать npm-зависимости для работы приложения не нужно. Сервер раздаёт только файлы приложения, не личную базу и не весь каталог проекта.

Для телефона разместить статические файлы по HTTPS, открыть сайт один раз с интернетом и дождаться статуса «Готово без интернета». Затем в меню браузера выбрать «Установить приложение» или «На экран Домой». После первоначальной установки расчёты, редактирование, языки, валюта и резервные копии работают без интернета. Простое открытие `index.html` через `file://` не подходит для PWA. `http://192.168…` также не заменяет HTTPS на телефоне.

Файлы для размещения: `index.html`, `styles.css`, `app.js`, `engine.js`, `db.js`, `i18n.js`, `sw.js`, `manifest.json`, `icon.svg`, `icons/icon-192.png`, `icons/icon-512.png`. Все находятся в одном каталоге с сохранением папки `icons`. Внешних CDN, шрифтов, API, аналитики и валютных курсов нет.

## Данные и обновление старой версии

- Сохранено имя базы `FinliteDB` и хранилище `templates` с ключом `name`. Существующая Dexie-база (физическая версия 10) обновляется без удаления или преобразования старых шаблонов. Добавляются хранилища настроек и истории. Типы `Fix` и `Percentage` старых правил поддерживаются.
- Обновляйте приложение **на том же адресе сайта, в том же браузере**. Другой домен, протокол, порт или профиль браузера имеет отдельное хранилище. При смене адреса/устройства используйте резервную копию.
- Если обновление базы заблокировано, закройте другие вкладки Finlite и откройте приложение заново. Не очищайте данные браузера ради обновления.
- Новая версия приложения сначала полностью кэшируется. Кнопка «Обновить приложение» появляется после готовности обновления. Черновик редактора сохраняется перед перезагрузкой. Расчёт на экране можно повторить после обновления; история расчётов не ведётся.
- Перед каждым изменением шаблонов автоматически сохраняется предыдущее состояние. В настройках доступны последние 20 состояний всей коллекции. Восстановление тоже сохраняет предыдущее состояние, поэтому его можно отменить следующим восстановлением.
- Перенос правила между шаблонами, изменение коллекции и создание записи истории выполняются в одной транзакции. При ошибке или нехватке места изменения откатываются.
- Одноимённый шаблон заменяется только после подтверждения. Редактор предупреждает, если исходный шаблон изменён в другой вкладке. Другие устаревшие операции отклоняются; обновите список и повторите действие.
- «Скачать копию» экспортирует JSON. «Загрузить копию» проверяет весь файл до записи, добавляет шаблоны и после подтверждения заменяет одноимённые. Остальные шаблоны сохраняются. Импорт восстанавливает шаблоны; язык, валюта и тема остаются настройками текущего устройства. История восстановления и незаконченный черновик в экспорт не входят.
- Браузер может удалить локальные данные при очистке или нехватке места. Приложение запрашивает постоянное хранение, но его доступность решает браузер. Скачанная копия необходима для переноса и независимого восстановления.

## Деньги и правила

Денежная арифметика использует целые сотые (`BigInt`), а не двоичные дроби `Number`. Допустимы неотрицательные суммы до `999999999999.99`, два десятичных знака, точка или запятая. Проценты — от 0 до 100 с двумя десятичными знаками. Остаток после процентного правила округляется до сотых по `ROUND_HALF_UP`, как в исходной Python-модели. Пример: из 100000 вычесть 30000, затем 10% → остаток 63000.

При нехватке средств проблемное правило не списывается: отдельно показаны нужная сумма, дефицит и реальный остаток. При нулевом остатке ненулевое правило останавливает расчёт, как прежде; нулевое правило не создаёт ложную ошибку. Все правила проверяются до начала расчёта. Старые некорректные значения остаются в базе: их можно исправить редактором, они не исправляются молча.

Валюта — только единица отображения **всех** сумм. Смена валюты не меняет числовые значения и не конвертирует деньги. Сотые сохраняются и отображаются даже для JPY/KRW, если они есть в исходной сумме. Это позволяет менять оформление без изменения логики расчёта.

Языки: русский, қазақша, English, Deutsch, Français, Español, 中文, 日本語, 한국어, Türkçe.

Валюты: KZT, USD, EUR, GBP, RUB, CNY, JPY, KRW, INR, TRY.

Ограничения: 500 шаблонов, 200 правил на шаблон, 4 МБ данных шаблонов. Копия сохраняется компактным JSON, чтобы помещаться в лимит импорта 5 МБ. Превышение лимита откатывает всю операцию. Уже существующие более крупные коллекции не удаляются и могут быть уменьшены.

## Интерфейс телефона

Страница использует обычную прокрутку документа. Нет глобального блокирования свайпов, drag-and-drop, принудительного `overflow` на `html/body` и запрета масштабирования. Порядок меняется доступными кнопками вверх/вниз, перенос в другой шаблон — выбором шаблона и позиции. Размеры полей не вызывают автоматическое увеличение при фокусе в iOS; кнопки рассчитаны на касание. Нижняя навигация учитывает безопасную область экрана. Светлая, тёмная и системная темы сохраняются.

## Проверки

```sh
npm test
```

Проверки браузера требуют отдельной зависимости только для разработки:

```sh
npm install
npx playwright install chromium
npm run test:browser
```

Можно указать `PLAYWRIGHT_MODULE` (путь к уже установленному пакету Playwright) и `BROWSER_EXECUTABLE` (путь к Chromium). Тесты поднимают временный локальный сервер и отдельный профиль с искусственными данными. Личная база не используется. Скриншоты сохраняются в `test-results/` и не входят в Git.

Покрыты: денежные граничные случаи и сохранение суммы, 10 полных словарей, импорт/экспорт, миграция прежней базы, атомарность и откат, конфликты записи, восстановление, буквальное отображение HTML в названиях, мобильные touch-жесты, размеры 320–1280 px, черновики, офлайн-перезапуск и обновление service worker. Мобильная эмуляция Chromium не заменяет окончательную проверку на физическом iPhone/Android.

При выпуске следующего изменения статических файлов увеличьте `VERSION` в `sw.js`. Не используйте время запуска для имени кэша или адреса регистрации service worker.
